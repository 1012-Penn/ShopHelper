# CH16：RAG 消融与答案可信度对照

日期：2026-10-26。分支：`codex/ch16-rag-ablation`，基线 `origin/main`=`dde19f3`。

## 实验口径与证据级别

- 复用 CH11 的检索、评测回答 prompt、确定性判分与快照校验；CH12 使用同一 `ControlledRagLoop`。检索组只改 `dense`、`bm25`、`hybrid`（Milvus RRF）或 `hybrid_rerank`；RAG 组只改 `baseline`、`decompose_once`、`controlled_loop`。
- 共用同一 Milvus Lite 快照（build `ebfd49478b37ef387c8b124319a450ed73a86ae2a4b9f4fc28d6a52b2ccaa0ba`，SHA-256 `b6b1fa237d03d2c0f8ddcfe8e003f13c4cb584f0764ac04c2d57ae834bbdca73`）、同一语料、改写策略、模型 `deepseek-flash`/温度 0、回答与证据判定 prompt；召回候选固定 50，答案上下文固定 top 10。冻结集使用 CH11 的 90 题 canonical SHA `f518fe1bd1d7c3c3cd95896a55a06f8160c3f5c82529c1639c8f6e6437fdabf7`；dev 60 题 SHA `a67210c9a2d56ce690eb35fc957f9b75fefb4da365e252f25532196bab5680f7`。
- dev 协议锁 SHA-256：`78bb6f71e3a563bb6681481abf3058ae1a1c217a453f55b135be54f3a85ea9b5`。锁包含运行脚本/指标实现 SHA、数据/索引、候选上限、预算和指标定义；frozen 运行前验证锁。冻结运行没有调参。
- 所有组均为离线缓存重放或本地检索；硬预算 `$0`，实际付费 API 调用 **0**、实际费用 **$0**。`cost_estimate_usd` 是缓存响应的等价估值，不是实付。缓存 miss 明确标未测，不用检索命中率代替最终答对率。
- P50/P95 是本地检索、循环与缓存路径 wall-clock，不是新模型调用的线上延迟；付费 API 延迟未测。索引校准仍标 stale，结果不外推到真实业务语料。

## 开发集：先验证流程

dev 共有 43 道有证据检索题、42 道有事实金标的目标答题。BM25 零费用跑完 60 题：R@3 **20/43 = 46.5%**、R@5 **25/43 = 58.1%**、MRR@10 **0.3390**。vector/RRF 只有 1/60 查询有本地嵌入缓存，rerank 组 0/60 完整；四组答案严格正确率均没有可测样本。CH12 三组也没有完整首轮轨迹，因为相同的 rerank 缓存缺口触发零预算守卫。

所以 dev 足以校验数据契约、缓存 miss 中止、逐题轨迹与聚合流程，不足以选择检索或答案路由。没有使用 dev 数字设阈值；正式冻结对照仅消费已经冻结的 CH11 查询/改写与证据缓存。

## 冻结集：检索消融

L1 分母只含 65 道 `required_evidence` 非空题。R@3/R@5 是 top-k 是否命中任一金标证据；MRR 为 MRR@10。表中答案指标按严格口径独立统计：分母为预期回答且有事实金标的 64 题；闸拦的可答题计错，缓存缺失单列未测。

| 策略 | R@3 | R@5 | MRR@10 | 严格正确率 | 条件覆盖 | 引用支持题 | 无证据断言 | 误拒 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| vector / dense | 37/65 (56.9%) | 46/65 (70.8%) | 0.4962 | 未测 0/64 | 未测 0/36 | 未测 | 未测 | 未测 |
| BM25 | 32/65 (49.2%) | 39/65 (60.0%) | 0.4143 | 未测 0/64 | 未测 0/36 | 未测 | 未测 | 未测 |
| RRF 融合 | 41/65 (63.1%) | 47/65 (72.3%) | 0.4642 | 未测 0/64 | 未测 0/36 | 未测 | 未测 | 未测 |
| RRF + 重排 | 40/65 (61.5%) | 49/65 (75.4%) | 0.5116 | **10/64 (15.6%)** | **0.7361 (36/36)** | **12/64** | **79/150 claims (52.7%)** | **7/70 (10.0%)** |

只有 RRF + 重排的 90 道回答缓存全部可精确重放；其余策略的最终回答严格样本没有命中，故不能声称 BM25、dense 或 RRF 的答案质量高低。RRF + 重排的严格正确率 10/64 与 CH11 历史 11/62 **不是同一分母**：CH16 主指标限定预期回答行为、把 3 个闸拦可答题计错，并排除 1 个带事实金标的 `clarify` 题；另外报告的 CH11 兼容“已尝试题”口径为 **11/62**，与历史报告一致。此处没有把 CH11 的历史报告改写。

以 dense 为同题参照的配对 R@3/R@5/MRR 得失（增益/损失/持平）：

| 策略 | R@3 配对 | R@5 配对 | MRR 均值差 |
|---|---:|---:|---:|
| BM25 | 4 / 9 / 52 | 2 / 9 / 54 | -0.0819 |
| RRF 融合 | 5 / 1 / 59 | 2 / 1 / 62 | -0.0320 |
| RRF + 重排 | 6 / 3 / 56 | 5 / 2 / 58 | +0.0154 |

RRF + 重排相对 RRF：R@3 少 1 题（配对 4 增、5 失、56 平），R@5 多 2 题（5 增、3 失、57 平），MRR 均值 +0.0474。融合对 BM25 的 MRR +0.0499；重排的净收益主要出现在 top 5 与排名质量，R@3 比 RRF 少 1 题。

按 CH11 bucket 的 R@3（分母依次为 entity mismatch 9、multi-constraint 14、multi-hop 16、policy conflict 8、single-hop 18）：

| 策略 | entity mismatch | multi-constraint | multi-hop | policy conflict | single-hop |
|---|---:|---:|---:|---:|---:|
| dense | 8/9 | 8/14 | 2/16 | 3/8 | 16/18 |
| BM25 | 8/9 | 8/14 | 0/16 | 0/8 | 16/18 |
| RRF | 8/9 | 9/14 | 1/16 | 5/8 | 18/18 |
| RRF + 重排 | 8/9 | 9/14 | 3/16 | 2/8 | 18/18 |

融合相对 dense 在 policy-conflict bucket 的 R@3 赢 2、无损；RRF + 重排的 policy-conflict R@3 为 2/8，低于 RRF 的 5/8。RRF + 重排的 multi-hop 为 3/16，高于 dense 的 2/16，但仍是主要检索失败桶。完整每题 gain/loss ID 与其他 bucket 的配对结果在 aggregate JSON。

## 冻结集：CH12 配对实验

三组都固定 hybrid + rerank、同答案 prompt、同温度和同评测器。baseline 90/90 可重放；两个复杂组各有 **67/90** 可测，另外 23 题在首轮证据判定缓存 miss 后被 `$0` 守卫中止。三个可答目标题 `FRZ-MULTI-11`、`FRZ-MULTI-14`、`FRZ-CONSTRAINT-13` 因此未测，不计作答案错。

## 费用、失败归因与建议

所有正式和 dev 运行费用均为 `$0`。下一次若统一安排新增付费调用，逐组预估如下；每组上限是建议的硬预算，不是授权：

| split / group | 估算 USD | 单组建议上限 USD |
|---|---:|---:|
| dev vector / BM25 / RRF | $0.0476–0.1019 / 组 | $0.12 / 组 |
| dev RRF + rerank | $0.0509–0.1052 | $0.12 |
| dev baseline / decompose / controlled | $0 / $0.0267–0.0533 / $0.0467–0.1000 | $0 / $0.06 / $0.11 |
| frozen vector / BM25 / RRF | $0.0713–0.1529 / 组 | $0.18 / 组 |
| frozen RRF + rerank | $0.0764–0.1579 | $0.18 |
| frozen baseline / decompose / controlled | $0 / $0.04–0.08 / $0.07–0.15 | $0 / $0.09 / $0.17 |

同跑七组的估算合计：dev `$0.2671–0.5642`、建议上限合计 `$0.65`；frozen `$0.4005–0.8466`、上限合计 `$0.98`。四个检索组互为备选；若只做路由/回答比较，应按组选择并先安排预算。费用细项与估算依据见各 split 的 `budget-estimate.json`。

RRF + rerank baseline 的 CH11 失败归因可复现为：引用支持失败 45 例、事实错误 13、漏条件 11、误拒 7、澄清缺槽 3、澄清过问 7、核验过度断言 1；标签之间可重叠。claim 级无证据断言是 79/150。冻结 RAG 的 23 个缺失缓存题包括两个 multi-hop、三个预期回答/有 gold 的 gate 题及 hard-negative/OOD/clarify 样本；它们没有被当作成功或失败答案。

**建议保留 `hybrid_rerank` 简单默认路由。** 它在这份冻结快照中是四个检索选项里 R@5/MRR 最好的一组，但政策冲突 R@3 只有 2/8，答案严格正确仍是 10/64，claim 级无证据断言 52.7%；不能据此宣布线上方案已解决。CH12 两个复杂路由在可测配对题没有净收益，且真实补检索分析路径零调用；在新缓存与统一预算下完成多跳/冲突题付费对照前，不应切换默认。CH13 LightRAG 仍属于独立实验分支，本报告不把它作为已验证线上方案。
