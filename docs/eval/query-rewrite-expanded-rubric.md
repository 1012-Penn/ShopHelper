# Query 改写扩展冻结评测规则

规则版本：`query-rewrite-expanded-v1`  
冻结日期：2026-10-27  
适用数据：`tests/eval/query_rewrite_ablation/frozen-v2.seeds.jsonl`

## 目的与边界

比较原话 `raw`、既有 `resolve -> rewrite`（`legacy`）与约束保护改写（`safe`）
在相同知识库快照、相同检索策略和同一批问题上的查询构造质量。

本评测只评查询意图、显式约束和检索证据覆盖，不生成最终客服答案，不调用 LLM
裁判，因此不声称答案正确率、引用忠实度或开放域泛化能力。

## 分母

- 总题数：60。所有成功、失败和模型改写异常都保留并计入各自分母。
- 检索覆盖：52 道有金标证据的可回答题；`complete@5/10`、`MRR@10` 只在此分母计算。
- 澄清约束：8 道缺少型号、订单或费用条件的歧义题；只评是否保留歧义、是否擅自补实体。
- 无需改写对照：10 道实体、订单或约束已完整的标准问法。
- 意图保持、锚点完整和错误实体：60 道全部计入。

## 固定运行条件

- 检索策略：`hybrid_rerank`。
- 候选数 50，最终上下文 Top-10；证据完整覆盖要求所有金标证据组均进入指定 Top-K。
- 查询模型、温度、重试次数与价格表记录在 `run-contract.json`。
- 只改变送入检索链的查询文本；索引、reranker 和金标映射固定。
- 单次付费测试硬上限为 USD 2.00；超限、超时或结构解析失败的请求不得从分母删除。
- 结果目录不得覆盖；失败题保留空检索结果和错误原因。

## 指标

| 指标 | 口径 | 分母 |
|---|---|---:|
| `complete_at_5` | 全部金标证据组均进入 Top-5 | 52 |
| `complete_at_10` | 全部金标证据组均进入 Top-10 | 52 |
| `mrr_at_10` | 首次完整覆盖全部证据组的倒数排名 | 52 |
| `intent_preserved` | 必需锚点完整、未使用禁用实体、需保持时未翻转否定 | 60 |
| `anchors_complete` | 每组必需实体/订单/日期/数值条件至少命中一个允许表达 | 60 |
| `wrong_entity` | 输出包含未被显式否定的禁用实体 | 60 |
| `failure_rate` | 检索或整体单题执行失败 | 60 |
| 延迟 | 逐题端到端 P50/P95，包含查询构造与检索 | 60 |
| 费用 | 定价表与调用台帐相加，区分查询模型、embedding 与 rerank | 60 |

配对比较使用同一题的三种查询，分别报告 `gains / losses / ties`。检索覆盖配对只含
52 道适用题；意图与约束配对含 60 道。不得用空检索或失败结果替代未执行题。

## 数据隔离与来源

- 60 道题在运行前冻结，语义族、模板、题面、ID 与旧 `dev`/`frozen-v1` 均不重叠。
- 新测试集的可回答题不与旧集共享金标 fact；事实和证据以 `corpus/` 中的
  `source_ref`、事实 ID 与 evidence ID 为准。
- 8 道歧义题引用真实知识文档范围，但没有单一金标答案，不因改写猜中某个合法实体
  而被算作“检索成功”。
- 同义换词不能新增题数；每题有独立语义族标签和结果缺口假设。
- 运行后不再改题、删失败题、换分母或按结果调整通过阈值。

## 报告口径

报告必须同时给出每个指标的分母、失败题、成本与延迟，并明确哪些部分来自真实模型/
真实索引、哪些来自冻结结果重放或离线汇总。60 题样本只作工程回归，不做显著性检验，
不使用“统计显著”“全面领先”等结论。
