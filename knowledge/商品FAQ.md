# 商品FAQ

## 售后

### 退货政策是什么?

支持七天无理由退货,商品需保持完好,凭订单号联系客服即可发起退货。

- 其他问法:退货规定 / 退换货政策

### 怎么申请退货?

在订单详情页点击「申请售后」,选择退货原因后提交,客服会在 24 小时内审核。

- 其他问法:退货入口在哪 / 怎么退

### 商品有质量问题怎么办?

质量问题可凭照片凭证免费退货,退回的运费由商家承担,退款原路返回。

### 保修怎么申请?

联系客服提供订单号与故障描述;非人为损坏免费维修,寄回费用按《售后手册》执行。

- 其他问法:保修申请 / 怎么保修 / 保修流程

### 维修需要多久?

维修时长与费用见《售后手册》保修与维修。

- 其他问法:维修时间 / 修多久 / 维修周期

### 人为损坏保修吗?

不免费;进水、摔损、私自拆机等按检测结果收费。

- 其他问法:人为损坏 / 进水保修吗 / 摔坏保修吗

### 换货和维修怎么选?

签收后 7 天内可换货;超过 7 天走保修维修。

- 其他问法:换货还是维修 / 换新还是修

### 支持 30 天无理由退货吗?

不支持;仅支持签收后 7 天内退货。

- 其他问法:30天无理由 / 一个月无理由 / 30天退货

## 物流

### 多久能发货?

现货商品 48 小时内发出,预售商品按页面标注时间发货。

### 物流一般几天到?

普通快递 3-5 天送达,偏远地区 5-7 天。

### 可以修改收货地址吗?

未发货可联系客服修改;已发货不能修改,需联系快递协商,平台不保证成功。

- 其他问法:改地址 / 修改地址 / 换收货地址

### 可以指定快递公司吗?

不支持指定快递,默认合作快递。

- 其他问法:指定快递 / 选快递 / 发什么快递

### 支持加急发货吗?

部分地区支持加急,加急费 10 元,优先安排发货,不承诺次日达。

- 其他问法:加急 / 快点发货 / 次日达

### 可以到店自提吗?

部分城市支持自提,下单时选择自提点;自提订单不支持货到付款。

- 其他问法:自提 / 到店取货 / 自己去拿

### 收到商品破损怎么办?

签收后尽快拍照或视频并联系客服;具体时效与责任划分见《售后手册》物流异常处理。

- 其他问法:破损 / 坏了 / 运输损坏

### 快递丢件怎么办?

尽快联系客服,提供订单号与物流截图;具体时效与处理方式见《售后手册》物流异常处理。

- 其他问法:丢件 / 没收到 / 快递丢了

## 交易

### 支持哪些付款方式?

支持微信支付、支付宝、银联卡。

### 可以开发票吗?

支持电子发票,下单时备注抬头,发货后 24 小时内开出。

### 会员有什么权益?

会员享 95 折、生日礼包、优先客服通道。

### 可以取消订单吗?

未发货可取消,到账时间见《退货政策》;已发货不能直接取消,可拒收或签收后走退货。

- 其他问法:取消订单 / 不想要了 / 撤单

### 支持分期付款吗?

部分商品支持 3/6/12 期,具体门槛与手续费以支付页为准。

- 其他问法:分期 / 分期付款 / 分期还款

### 支付失败怎么办?

先检查余额或限额;如已扣款但订单未成功,费用会原路退回;30 分钟内未支付订单自动取消。

- 其他问法:支付失败 / 扣款了 / 付不了款

### 可以合并订单或拆单吗?

同地址未发货订单可尝试合并,合并支付按总额计算包邮门槛;拆单后各子订单分别计算,可能不再满足包邮门槛。

- 其他问法:合并订单 / 拆单 / 一起发货

### 支持货到付款吗?

不支持货到付款;其他支付方式见「支持哪些付款方式」。

- 其他问法:货到付款 / 到付 / 见面付款
