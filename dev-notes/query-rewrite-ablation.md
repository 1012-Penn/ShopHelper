## 2026-10-27 · 历史补全与约束保护

目标是在现有 `resolve -> rewrite -> hybrid_rerank` 链路上判断“何时改写比直接检索原话
更可靠”，而不是重造检索架构。新增 `app/query_guard.py`，保护型号、订单号、日期、
政策版本、数字单位与否定极性；历史补全只允许引入历史/当前材料里已有的硬锚点。

保护不是让模型“修得更像标准问法”。若归一化删除当前显式锚点、引入无依据实体、
翻转否定，或同义句丢失约束，直接把该层回退到输入句。resolve 的 trace 记录
`guard=pass|fallback` 和违规原因；re-rewriter 返回 `RewriteDecision`，保留
被丢弃的同义句供审计。
