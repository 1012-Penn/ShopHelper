## 结果摘要

### 检索与答案（frozen-v1）

65 道有证据题中，dense/BM25/RRF/RRF+rerank 的 R@3 分别为 `37/65、32/65、41/65、41/65`；R@5 为 `46/65、39/65、47/65、50/65`；MRR@10 为 `.4962、.4143、.4650、.5159`。严格答对数分别 `8/64、12/64、8/64、8/64`。RRF+rerank 召回排名最高，但 strict answer 不高于 BM25；详见 [`docs/eval/ch16-rag-ablation-report.md`](../docs/eval/ch16-rag-ablation-report.md)。

同时观察到 RRF+rerank 的 R@5 相对 dense 只有 `6` 题新增、`2` 题损失，精确 McNemar `p=0.289`，不能称为显著提升。四个检索组的答案闸也不一致：前三组未调用证据蕴含判断器，RRF+rerank 在 90 题上均调用。因此检索排序可以直接比较，答案指标只代表各组默认端到端路径。

### CH12 配对

Frozen baseline、decompose_once、controlled_loop 均完成 90/90 题。三组严格正确均 `8/64`；复杂路由对 baseline 严格答案均 0 增、0 失、64 平。multi-hop 桶仅 `FRZ-MULTI-01` 出现 R@5/MRR 损失；policy-conflict 题逐题无严格答案或检索净收益。Controlled 的 GapAnalyzer 逻辑请求复用 decompose 的精确响应缓存，因此实际 `$0.008586` 是共享缓存路径下的边际费用；冷启动估值与线上 API 延迟分开报告。

确定性分拣复算后，decompose_once 与 controlled_loop 的误拒均为 `3/70`，baseline 为 `7/70`；三组 claim 级无证据断言分别为 `89/152、89/152、85/148`。这些是判分修正结果，不是新增模型输出。

### 实际费用

总账 1,274 次调用全部成功且闭合，金额与费用账本按 `$0.705838302` 完全对账。15 个丢失实验上下文的初次尝试费用 `$0.019099008` 单列；不能归给任何比较组。分组明细、调用类型和对账结论见 [`attempt-reconciliation.json`](../tests/eval/rag_ablation/runs/attempt-reconciliation.json)；原始在线日志不会提交。

本次冻结合计费用：检索 602 次外部 API、422 次付费调用，约 `$0.315424326`；CH12 161 次外部 API、73 次付费调用，约 `$0.087341100`。Dev 归因调用约 `$0.283973868`，另有上述未归因 `$0.019099008`。

本次审计复算的模型调用与费用均为 `0`。实际费用是按保存 token usage 和价格快照的事后估算，不应当作供应商发票。
