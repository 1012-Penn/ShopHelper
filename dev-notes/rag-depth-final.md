# RAG 深度补强最终集成

## 观察

四个来源分支分别证明了证据面、缓存、受护改写和答案质量，但集成前仍有两个风险：一是工厂配置可能只把单项能力接入评测器而没有接入真实应用；二是合并后的规则修复可能改变已保存的独立结果口径。

## 定位与改动

- 复查四个来源分支，统一 `Settings`、`make_retrieval_chain`、LangGraph state、trace 与 `query_faq` JSON 的 selection diagnostics。
- 保留保守默认：证据面与缓存 opt-in，缓存强制语料版本，受护改写默认开启且可回滚。
- 修复地区运价被通用运费挤掉、保修损坏题漏质量认定证据两处集成问题。
- 扩展真实应用评测 CLI，支持固定 case、独立预算台账、调用数与墙钟停止规则，并记录 slate/cache/guard 配置快照。
- scoped lint 清理 changed Python files，不宣称全仓库 lint 绿色。

## 结果

- 零调用重放：合并 128 题完整证据覆盖 `88/128 -> 127/128`，39 胜 0 失；但独立 holdout 的首轮结果仍是 `13/20 -> 18/20`，`20/20` 只是事后重放。
- 170 题答案：126 道证据答案 `94 -> 102`，全部确定可评 `137 -> 145`，9 胜 1 负 160 平；17 道新增完整覆盖题中只有 2 道直接转化为答案收益。
- 真实应用 3 题冒烟：事实、条件、实体全过，0 技术失败，3 题均看到 guard=pass、rerank pool=50、10 条证据和预期 facets；引用 2 uncertain、1 unsupported。费用 `$0.00826266`，22 次调用，低于 $2/40 次/600 秒停止线。
- 定向回归 `241 passed`；修复评测CLI后全量 `1213 passed, 2 skipped, 1 xfailed`；scoped Ruff 通过。

## 成本与边界

来源有效成本合计 `$0.62027278`；集成重放 0 费用；真实应用冒烟 `$0.00826266`；最终有效小计 `$0.62853544`。答案质量分支的保守台账为 `$0.86687129 / $2.00`，含失败与预留，不等同发票。

本结论支撑“集成可验收、证据面可 opt-in、受护改写可默认”，不支撑“生产答案质量普遍提升”或“引用质量已解决”。
