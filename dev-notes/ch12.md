### 本轮实现

**新建**
- `app/rag_loop.py`:受控循环核心。首轮原查询(与基线同一调用)过闸即放行(零额外 LLM 调用);
  未过闸才循环「蕴含再判(同一判断器/prompt/温度)→ 缺口分析 → 子查询规范化去重 →
  补检索(use_rewrite=False)→ max-score 合并」;全部轮次后对最终证据终判(decompose_once =
  max_rounds=1 特例)。放行 = 分数闸 + 蕴含判断器双满足;分析器 `sufficient/answer` 不参与放行。
  停止原因 11 类;BudgetExceeded 穿透,其余故障按已知证据谨慎收敛。
- `app/graph/agentic.py`:`agentic_retrieve` 节点,循环在 `to_thread`;充分→agent(citations
  全量单发),clarify→澄清回复,refuse/收敛→REFUSAL_MARKER + 落池 + 转人工动作,
  escalate→说明冲突 + 转人工;逐轮 on_step 落审计。
